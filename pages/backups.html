Backups and moving devices

A backup holds your whole account: every app and its data, your notes, agent chats, settings, model connections and MCP servers. Everything is in Settings > Backups.

Backups on this device

Chrysalis backs your account up once a day while it runs, and keeps the last five. Change how many it keeps, or turn it off, under On this device. Back up now makes one right away; those stay until you delete them.

Only files that changed since the last backup take new space, so daily backups stay small. Each row shows the backup's size and how much of it was new. On Android every backup is a full copy, so keep fewer there.

Restore puts your account back the way it was at that point. Before it does, Chrysalis backs up the account as it is now, so a restore can be undone by restoring that one.

Backups in Google Drive, Dropbox or another folder

An admin can send backups to any folder on the computer running Chrysalis. Under On this device, press Choose folder. Google Drive, Dropbox, OneDrive and iCloud Drive folders that their desktop apps keep in sync show up as one-click choices, so a backup there is copied to the cloud with no extra sign-in. Any other folder works too, such as one on a second disk.

Each account's backups go in Chrysalis/<account> inside the folder. Backups made before the change stay where they were and are still listed. Rows kept in the folder say in your folder. If the folder is not there when a backup runs, for example a disk is unplugged, the backup fails and says so instead of going somewhere else. Use data folder switches back.

To restore on a new computer, install the cloud app there, sign in with an account of the same name, choose the same folder, and the backups appear in the list.

Move to another device

Use this to move everything from your computer to the Android app, from the phone back to a computer, or between two computers. Both devices need to be on the same network.

  1. On the device that has your data, open Settings > Backups, choose Send and press Make a code. It needs Allow other devices on my network turned on in Settings > Server.
  2. On the other device, choose Receive. Type the address and code shown on the first device, or press Scan QR code and point the camera at it.
  3. Press Check to see what will arrive, then Replace my account.

A code lasts 15 minutes and works once. The account on the receiving device is replaced, and a backup of it is kept there first. Receiving is for admin accounts; other accounts can restore from a file.

The transfer is not encrypted unless Chrysalis runs over HTTPS. Use it on a network you trust, and leave Include API keys and sign-ins off if you would rather paste your keys again.

Backup files

Download backup saves the account as one .tar file. Keep it somewhere safe, or carry it to another device and use Restore from file there. API keys are left out unless you tick the box.

What is left out

  • The workspace's git history stays on each device. A restore is recorded as one new change in it.
  • Downloaded app packages and built files. Chrysalis fetches and builds them again.
  • Approvals for MCP servers and apps that run a program on the computer. Approve them again on the new device.
  • Apps from a file or another device are not marked official until their next update.
