Chrysalis

The AI frontend you can reshape just by asking.

Chrysalis runs on your own computer or phone and opens in your browser. Pick apps from the built-in Store, and every one of them is plain files the built-in agent can change while you watch. Ask for a feature and it builds it. Your chats, characters and keys stay on your device.

What you get

Yours, on your device

One download for Windows, macOS, Linux or Android, or a Docker container. Nothing else to install, and your data stays in its own folder.

Install it

Apps you can change by asking

Every app is a normal web project. Tell the agent what you want and it edits the app while it stays open, with every change kept in history.

Meet the agent

Any model provider

Connect the providers you already use, or a model running on your own machine. Keys never leave the server.

Add a connection

A Store with a safety check

Install apps in one click. Before anything runs, you see what an app's plugins are allowed to do.

Apps and the Store

Updates that keep your edits

App updates merge with the changes you or the agent made. Your chats and characters are never touched.

How updates work

Build anything

Games, trackers, dashboards, visual novels. Apps can call models, stream replies, generate images and speech, reach web APIs and run on a timer.

What you can build

Every change can be undone

Your apps and their data live in a git repository. Each file the agent writes is saved to its history, so any change can be put back.

How history works

Plugins in a sandbox

The server side of every app runs in a WebAssembly sandbox and can only use the permissions you approved.
